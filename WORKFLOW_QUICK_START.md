# Document Generation Workflows - Quick Start Guide

## 🎯 Which Workflow Should I Use?

### 🎨 Use "Mimic a Document" When:
- You have a document with the exact style/format you want
- You need to create multiple similar documents with different values
- You want to maintain consistent formatting across documents
- **Example**: You have a great NDA template and need to create 10 more for different clients

### 🤖 Use "AI-Guided Builder" When:
- You're creating this type of document for the first time
- You want to make sure you don't miss any important fields
- You prefer step-by-step guidance
- **Example**: You need to draft a legal memo but aren't sure what information is required

### ⚡ Use "Quick Generate" When:
- You know exactly what fields you need to fill
- You want the fastest path to a finished document
- You're familiar with the document type
- **Example**: You've created 20 contractor agreements and just need to do one more quickly

---

## 🎨 Mimic a Document - Step by Step

### Step 1: Upload Your Reference
1. Go to **Generate Document** tab
2. Click **🎨 Mimic a Document** tab
3. Click the file uploader
4. Select a PDF, DOCX, or TXT file

### Step 2: Analyze the Document
1. After upload, click **🔍 Analyze Document Structure**
2. Wait 10-30 seconds while AI analyzes
3. Review the extracted information:
   - Document type
   - Tone and style
   - Key fields found

### Step 3: Edit Values
1. Modify any extracted field values
2. Change party names, dates, amounts, etc.
3. All fields are editable

### Step 4: Generate
1. Click **✨ Generate Document**
2. Wait for generation (30-60 seconds)
3. Review the generated document

### Step 5: Download
1. Scroll to **Preview & Edit** section
2. Make any final edits in the text area
3. Click **⬇️ Download .docx**
4. Open in Word/LibreOffice for final review

---

## 🤖 AI-Guided Builder - Step by Step

### Step 1: Select Document Type
1. Go to **Generate Document** tab
2. Click **🤖 AI-Guided Builder** tab
3. Choose your document type from dropdown
4. Click **Start Building →**

### Step 2: Answer Questions
1. Answer the first question
2. Click **Next →** to proceed
3. Use **← Previous** if you need to go back
4. Watch the progress bar at the top

### Step 3: Review Answers (Optional)
1. Click **📋 Review Your Answers** at any time
2. See all answers you've provided so far
3. Navigate back to change anything

### Step 4: Complete & Generate
1. Answer the final question
2. Click **Generate Document ✨**
3. Wait for generation (30-60 seconds)
4. System automatically moves to preview

### Step 5: Download
1. Review in the **Preview & Edit** section
2. Make any inline edits
3. Click **⬇️ Download .docx**

---

## ⚡ Quick Generate - Step by Step

### Step 1: Select Type
1. Go to **Generate Document** tab
2. Click **⚡ Quick Generate** tab
3. Choose document type from dropdown

### Step 2: Fill the Form
1. All fields appear in one form
2. Fill out required information
3. Use placeholders as examples
4. Optional: Check SEC EDGAR data if relevant

### Step 3: Generate
1. Scroll to bottom of form
2. Click **✨ Generate Document**
3. Wait for generation (30-60 seconds)

### Step 4: Download
1. Scroll to **Preview & Edit**
2. Edit if needed
3. Click **⬇️ Download .docx**

## 💡 Tips & Best Practices

### For Mimic Workflow
- Use clean, well-formatted reference documents for best results
- PDFs with complex layouts may not analyze perfectly
- The clearer the reference document, the better the output
- Try DOCX files for most accurate field extraction

### For Guided Workflow
- Answer questions as completely as possible
- Use the Previous button to review and refine answers
- The "Review Your Answers" summary is helpful before generating
- You can skip optional questions by leaving them blank

### For Quick Workflow
- Have all information prepared before starting
- Use the placeholder text as formatting examples
- The more detail you provide, the better the output
- SEC EDGAR data adds context but increases generation time

### General Tips
- **Always edit before downloading**: The generated text is a draft, review it carefully
- **Save frequently**: Use the download button as soon as you're satisfied
- **Iterate**: If the first generation isn't perfect, edit and download, or regenerate
- **Check formatting**: Open the .docx in Word to ensure it looks correct

## 🔧 Troubleshooting

### "AI Provider Not Configured" Error
**Fix**:
1. Go to **Settings** tab
2. Select **LLM Provider** sub-tab
3. Choose Ollama (local) or OpenAI (cloud)
4. Follow the setup instructions

### Analysis Takes Forever (Mimic Workflow)
**Fix**:
- Check your LLM is running (Ollama) or API key is valid (OpenAI)
- Try a smaller reference document (under 10 pages)
- Refresh the page and try again

### Guided Workflow Stuck on One Question
**Fix**:
- Refresh the browser to reset
- Try the Quick Generate workflow instead
- Check browser console for errors

### Generated Document Looks Wrong
**Fix**:
- Edit directly in the Preview & Edit section
- Regenerate with more detailed input
- Try a different workflow approach
- Remember: All documents need attorney review

### Can't Download Document
**Fix**:
- Make sure document was generated successfully
- Check for error messages in the UI
- Try clearing browser cache
- Refresh and regenerate if needed

## 📝 Example Scenarios

### Scenario 1: Creating Multiple NDAs
**Best Workflow**: 🎨 Mimic a Document
1. Upload your best NDA template
2. Let AI analyze structure
3. Change party names and dates for Client A
4. Generate and download
5. For Client B, upload same template again
6. Change values for Client B
7. Repeat as needed

### Scenario 2: First Time Writing a Legal Memo
**Best Workflow**: 🤖 AI-Guided Builder
1. Select "Legal Memorandum"
2. Follow the guided questions
3. AI asks for: To, From, Date, Re, Questions, Facts, Jurisdiction
4. Answer each carefully
5. Generate professional memo with proper structure

### Scenario 3: Routine Contract Modification
**Best Workflow**: ⚡ Quick Generate
1. Select "Contract / Agreement"
2. Fill in all familiar fields quickly
3. Use SEC EDGAR if referencing a public company
4. Generate in one shot
5. Quick review and download

## ⚠️ Important Reminders

1. **All generated documents are drafts** - They require attorney review
2. **This tool does not provide legal advice** - It's a drafting assistant
3. **Verify accuracy** - Always check names, dates, amounts, and terms
4. **Local vs. Cloud**: Ollama (local) = private, OpenAI (cloud) = sent to OpenAI
5. **Save your work**: Download documents immediately after generation

## 🎓 Learning Path

**Beginner**:
1. Start with **AI-Guided Builder** for a simple contract
2. Try **Quick Generate** for the same type
3. Compare the workflows and choose your preference

**Intermediate**:
1. Upload a template with **Mimic a Document**
2. Experiment with different reference documents
3. Learn which document types work best with which workflow

**Advanced**:
1. Create your own template library
2. Use Mimic for complex multi-party agreements
3. Combine workflows (analyze with Mimic, generate with Quick)
